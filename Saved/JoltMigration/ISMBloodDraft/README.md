# ISM blood callback draft

Research-backed draft only, 9 September 2026. These files are outside active module source and have not been compiled or executed. No existing source or asset was changed. Parent owns review, integration, builds and runs.

`ProphecyJolt::ISMBloodDraft::ValidatePromotion(World, Placement, Report, Error)` is synchronous and requires an initialized real-RHI Game/PIE world. Use an isolated clear location. It creates three transient cube instances, invokes two synthetic exported-particle callbacks with Size 2 and Size 1, validates the two actual Blueprint promotions and mask pixels, exercises one repeat, and destroys fixture actors. It does not run a Niagara simulation or migrate static bodies to Jolt.

## Why an unfinished deferred Blueprint can execute here

- UE 5.7 `Actor.cpp:1452–1486`: `AActor::ProcessEvent` requires executable script/native code and `World->AreActorsInitialized()` (or editor scripting override). It does **not** require this actor's `IsActorInitialized()` or `HasActorBegunPlay()`. The draft uses the normal game-world path and changes no global script-execution flags. A new non-initialized test world would silently skip this callback; the draft rejects it.
- `Actor.cpp:4331–4339`: `bDeferConstruction=true` skips `FinishSpawning`. SCS/construction execution occurs in `FinishSpawning` at 4388; subsequent `PostActorConstruction` leads to initialization/BeginPlay. The draft sets `RF_Transient` and `bDeferConstruction` through the exact underlying SpawnActor parameters and never calls FinishSpawning.
- `CoreUObject/Private/UObject/UObjectGlobals.cpp:3979` creates the persistent Blueprint ubergraph frame during UObject construction, before the deferred actor's FinishSpawning/SCS boundary. The callback's frame is not inherently missing just because actor construction was deferred.
- This is a **bounded diagnostic of the callback**, not a recommended production actor lifecycle. It checks the actor remains uninitialized and has not begun play before and after invocation, and checks real side effects (the reflected `SM impostors` array, actor transforms, queued stamps and pixels). Source compatibility is established; runtime viability remains untested.

## Exact inspected graph

Source: `Saved/JoltMigration/Inventory-20260909-051135/AssetManifest.json`, blueprint `/Game/_mygame/blood2/A_DecalManager.A_DecalManager`.

- `EventGraph.K2Node_Event_3` (`3CAB16E54063F4AB688CC4B67A27B3CB`), ReceiveParticleData, calls `NewFunction(Array<FBasicParticleData>)`. NiagaraSystem and SimulationPositionOffset are unconnected.
- `NewFunction.K2Node_CallFunction_3` (`A06F947D429D70F945A024B2BC393B2C`) does the complex trace. Start = Position + Velocity. End is built as Start + (-2 * Velocity), hence Position - Velocity. Size == 1 selects TraceTypeQuery4; otherwise TraceTypeQuery1. Ignore self is true. The draft uses the real same UE helper to preflight intended Item/Face identity and reports resolved collision channels.
- `K2Node_IfThenElse_0` checks HitActor == `floor`. Its false branch casts HitComponent to ISM. Its true branch terminates at an unconnected knot.
- Cast-success branch uses source Hit.Item to get world transform, spawns StaticMeshActor, sets Movable, copies source mesh, sets Static, appends to `SM impostors`, sets original instance scale zero, rebuilds HitResult with promoted actor/component, and calls existing `paint manager` TryPaintFromHit using `brush radius` (native float).
- Required reflected properties are exactly `paint manager` (AProphecyBloodTexturePaintManager object), `floor` (StaticMeshActor object), `brush radius` (float), `SM impostors` (StaticMeshActor array). These are initialized on the deferred instance, never on its CDO. The draft also verifies the `ProphecyFoliageDecalGrid` field exists and is null because SCS did not run.
- UserConstructionScript's only connected entry has no execution successor. The promotion success path needs no SCS-created component. The promoted StaticMeshActor itself is spawned normally by the existing Blueprint node and has its native mesh component.
- Repeat hits on a promoted ordinary mesh take the failed-ISM-cast branch. This calls `AddFloorHitToFoliageDecalGrid` and `GetActiveFoliageGridDecals` with the null SCS grid, then existing `Double Printtt`. Both native grid helpers are null-safe (`ProphecyFoliageDecalGridComponent.cpp:937–940,960–963`). Thus the draft can validate no duplicate promotion and unchanged existing mask, **not** another texture stamp. It deliberately retains the inspected debug-print behavior.

## Geometry, materials and pixel evidence

- Two rotated, positively scaled instances plus an untouched neighbor share the original engine cube mesh/material. No ISM material override is introduced, since the existing promotion graph copies the mesh but not component material overrides.
- The callback's zero-scale update is also checked through direct ISM component tracing: UE `InstancedStaticMesh.cpp:4344–4353` terminates an existing body for a nearly-zero world scale. The replacement complex world hit must resolve the newly promoted actor and source UV data.
- Existing mappings come from live native paint managers or `/Game/Prophecy/BloodTexturePainting/BP_BloodPaintManager.BP_BloodPaintManager_C`. Fallback is explicitly reported as `/Game/Prophecy/BloodTexturePainting/M_BloodPaint_RuntimeTest.M_BloodPaint_RuntimeTest`; brush is `/Game/Prophecy/BloodTexturePainting/M_BloodBrush_Circle.M_BloodBrush_Circle`.
- Editor auto-create/update/overwrite/save are false; no material graph or usage is changed. Shader preparation now matches the active `BloodFixture::PrepareMaterial`: get the resource for the world's shader platform, call its `FinishCompilation()` first (also drains pending asynchronous material-DDC/cache work), and only call synchronous `CacheShaders` if that resource/map is still absent or incomplete; reacquire and finish afterward. All compilation/cache calls and the precompile-mode include are `WITH_EDITOR` guarded. Shipping only validates its existing cooked world resource/map and reports missing data. Readiness is based on the current world's complete shader map, with the broader `Material.IsComplete()` retained as diagnostic data.
- `FinishAllCompilation` alone proved insufficient for asynchronous material DDC. Unconditional `CacheShaders` invalidated the already-ready brush on the second fixture call. The parent reports the conditional resource-level path passed the static pixel test with 524 changed localized pixels; that active-helper result is evidence for the preparation choice, **not** an execution result for this ISM draft. The preparation may block and is not performance measurement.
- Per-receiver MID→BloodMaskRT identities are inspected, every fresh mask must be black before flush, each stamp must produce localized nonblack RGB pixels, second painting must leave the first mask byte-identical, and neighbor transform/source material must remain unchanged. Real-RHI readback proves masks; no screenshot or visible final-material claim is made.
- Cleanup occurs synchronously with no world ticks/latent commands. It restores manager-owned materials and destroys the source, paint manager, deferred actor and newly spawned static actors. Integration review should preserve this no-world-tick condition or replace actor-difference cleanup with an explicit spawn observer.

## If the guarded deferred route fails

Do not call FinishSpawning on this actor in the live world to make the test pass: that would run unrelated BeginPlay/Niagara setup. First retain the report and log whether the function/property guards or callback side-effect checks failed. The bounded supported-lifecycle alternative is a separate initialized game world in which actors are initialized but world BeginPlay is intentionally not dispatched, then normally finish-spawn the Blueprint so SCS exists; validate the world lifecycle with UE source before implementation. A native reimplementation of promotion would test an adapter instead of this existing Blueprint transaction and must be labeled separately. No fallback is automatically executed by this draft.
