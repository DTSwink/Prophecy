# Idle breathing

`Set Breathing Mode` selects **No breathing**, **Upper body only**, or
**Upper body and pelvis** for an agent. Upper body and pelvis is the default;
no Blueprint call is needed to enable it. `Get Breathing Mode` reads the choice.

`Set Breathing Multipliers` exposes **Pelvis Multiplier** and **Upper Body
Multiplier**, independently defaulting to1. Zero stops new deltas for that
region;2 doubles each successive translation and rotation-angle delta. Negative
values become0; nonfinite inputs are rejected. Adjusting strength does not reset
the running phase or remove motion already accepted. Reset retains both values.
Unit strength takes the original fast path; non-unit rotation uses axis/angle
scaling. Pelvis strength0 skips the leg solves and lower-state encoding.

`Set Breathing Speed Multiplier` takes Agent and Multiplier(default1), snaps
to the nearest of **0.3,0.4,0.5,0.6,0.7,0.8,0.9,1.0**, and returns **Applied
Multiplier**. Midpoints select the higher rate; values outside the range clamp
to its endpoints. Invalid agent/nonfinite input returns0 without changing state.
Changing speed preserves the current phase and both amplitude settings. Reset
or a new eligible idle restarts phase zero while retaining the selected rate.

All eight rates are pre-baked together on one shared tenth-source-tick grid.
At each authored game tick the selected rate advances3..10 entries; skipped
publication ticks advance by the elapsed integer tick count. This gives exact
rates, including0.7/0.9, without rounded loop durations or runtime interpolation.
There is one shared table, not eight copies per agent. Default1 uses exactly the
original samples. Speed changes add no per-bone computation, animation sampling,
timer, allocation or inference; only integer phase advancement before the
existing successive-delta application. Amplitude scaling still applies afterward.

The gate requires exactly zero movement input and ordinary NN locomotion,
or any D/S phase, including reach, attachment, sliding and return. Attacks,
defense, attack FK/dodge returns, get-up, reaching and animation layers exclude
breathing. Throughout D/S it enters the accepted underlying NN pose; the authored
body/head/arm controls retain ownership and can mask upper-body breathing before
return. The gripping branch still follows the sword until release. This does not
add a second breathing overlay on top of D/S or change the accepted lab motion.
A disabled/ineligible agent keeps no progressing breathing
phase. A new idle starts its delta clock at frame zero. Movement or an authored action
stops new breathing deltas; it never subtracts the motion already accepted. Reset restarts the phase and retains the
selected mode. The gate follows the existing pose-publication cadence.

The source is `M_Neutral_Stand_Idle_Loop`, sampled at60 authored ticks/second
for its10-second loop. Each upper bone stores its parent-local translation
difference and `Q(t) * inverse(Q(0))`. Pelvis uses the corresponding mesh-local
offset. Runtime takes the difference between successive samples (translation
subtraction and `Q(next) * inverse(Q(previous))`) and applies that increment to
the new NN pose once. It does not repeatedly add a frame-zero offset. Hierarchy traversal is independent of PHAT ordering,
including neck_01 → neck_02 → head. No root displacement from the clip is used.

Upper-only leaves all lower-body transforms untouched. Pelvis mode carries
the upper body and hips, then solves the two legs while keeping the original
NN foot/toe positions and rotations. Segment lengths are preserved. If an NN
leg is too extended to accept the requested pelvis motion, only the pelvis
offset is reduced to the reachable range. It does not stretch legs or move feet.

Timing uses the manager's existing unpaused game-tick count:600 ticks per loop at1x,
independent of FPS, wall time and policy frequency. Existing interpolation
presents the accepted previous/current endpoints. Only the new endpoint receives
a delta; repeated publications of the same tick do nothing. There is no new ticking component or timer.

The table is one shared immutable2,856,476-byte array. No runtime animation load,
decompression, disk read, or extra NN inference. Bone indices and parents bind
once per layout; warm updates allocate nothing. The ordinary path uses upper FK
composition and, in pelvis mode only, two analytic leg solves per endpoint.
The table is generated by `Tools/NN/ExportBreathing.py` through the existing
Unreal remote runner. Its header records the source asset hash. Rerun it after
an intentional source-animation change, then rebuild; no silent runtime rebake.

Breathing modifies the accepted pose after the NN step. The existing component-
pose encoder writes the changed upper state, and pelvis/leg state in pelvis
mode, into the published and current recurrent buffers. The current upper-body
base and pelvis feature are refreshed in the same root frame. Existing output
stages shift current into previous on the next policy step; breathing neither
replaces that previous sample nor creates a second history. The existing
completed-target physical-feedback path then adds physical error to this
already corrected state. No alignment switch or physical-feedback policy changed.

D/S therefore inherits the actual accepted breathing pose. Stopping the delta
injection does not expose an older unmodified pelvis pose. The NN is still free
to predict its own subsequent motion; this does not guarantee it will reproduce
the original idle animation exactly or preserve every velocity.

Implementation: `ProphecyBreathing.cpp`, generated `ProphecyBreathingData.h`,
`ProphecyBreathingLibrary.h`, manager publication/accepted-history hook and reset.
