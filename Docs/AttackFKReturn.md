## Conditional slash winding (October 8)

At return entry only, slashL/LU/LD request clockwise upperarm_r recovery and
slashR/RU/RD request counterclockwise recovery, viewed from above in Unreal's
X-forward/Y-right coordinates. The rule applies only when shoulder-to-elbow
points inward in spine_05 coordinates (Manny's local +Z is the right side),
and the existing return would move that direction the wrong way horizontally.
The user's deliberate heuristic treats such inward poses as being in front.
Outward, already-correct, nearly vertical/ambiguous and other-family returns
retain the old cached curve. All six slashes use the sword's right arm.

The correction selects the complementary quaternion arc to the **same** local
idle orientation, rather than negating the destination angle. The first slashL
fixture changes a 171.7938-degree continuing arc to the opposite 188.2062-degree
arc. It does not introduce a yaw/Euler decomposition or collision routing.
Return duration, easing, momentum envelope, Hold/Trim and NN takeover stay the
same. Angular velocity corrections are computed after route selection so an
enabled inertia retains its outgoing velocity. Descendants follow the shoulder
through existing FK. This is a handoff-only decision: no extra per-tick branch,
pose pass, allocation, inference, profile option or reflected node.

Verification inputs are generated by `Tools/NN/BuildSlashWindingFixture.py`
from the independent legacy lab fixture and the small captured
`Tools/NN/Fixtures/SlashLReturnWinding.json`. The editor-only console diagnostic
`Prophecy.FKReturn.VerifyWinding` runs pure native math without entering global
automation mode or changing the scene. The same check is registered as
`Prophecy.NN.FKReturn.SlashWinding` for headless automation. Old JS runtime parity
explicitly excludes intentionally redirected paths; its original pure-curve
parity still covers all variants. The standalone lab itself is unchanged.

Equivalence means identical output for identical incoming poses/settings.
A corrected return can change subsequent NN history or contacts, so later
attacks in a continuous gameplay sequence need not reproduce an old run.

The independent inertia envelope uses x=elapsed/effective duration. With a
positive inertia hold H, phase=clamp((x-H)/(1-H),0,1)^2; with H=0, phase=x.
Momentum is elapsed*(1-phase)^3*exp(-decay*phase/(.025+.45*main*bone)).
This inertia hold is separate from **Alpha Hold**, which controls NN takeover.
Hands remain excluded from their own angular and offset inertia.

## Blueprint controls

- **Set Attack FK Return**: Agent, Enabled (true), NN Takeover Coefficient (1), and 16 attack vectors, each **X=Hold .1 / Y=Trim .34**. For `x = clamp(elapsed / return time, 0, 1)` and hold `h < 1`, the NN weight is `clamp((x-h)/(1-h),0,1)^coefficient`. Hold 1 has weight zero before the deadline and one at completion. With hold .5, coefficient 1 gives 50% NN at 75% of the total window; coefficient 2 gives 25% there. Hold zero retains the previous curve. The coefficient must be finite and at least .01; hold must be finite in [0,1]. Return time zero bypasses recovery. **Time follows the project-wide golden rule: elapsed = unpaused game ticks / 60**, independent of FPS, DeltaSeconds and time dilation. A hitch spends one tick. The .26 default completes on tick16, about3.2 real seconds at5FPS. This corrects the initial world-time implementation.

Easing controls the lab-to-idle path independently: `blend = lerp(x, quinticSmoothstep(x), easing)`. The original October 2 envelope (superseded by the inertia hold/decay formula above) added outgoing angular momentum `elapsed * (1-x)^3 * exp(-elapsed/(duration*(0.025+0.45*effectiveInertia)))`. Position offsets follow spherical direction arcs while preserving the outgoing segment length. The final parent-local blend approaches the current NN local rotation and offset; at completion the original NN transforms pass through without a quaternion round trip.

## Cost and fidelity

Handoff caches bone indices, parent-local outgoing poses, shortest rotation arcs and angular velocities once. Curve sampling uses fixed stack storage and float quaternion math, shares exponential decay between equal group settings, skips zero momentum, and special-cases coefficients 1 and 2. The regular upper batch contains only agents needing prediction; zero-weight returns and authored owners are omitted, and an empty batch does not invoke the network. Packing buffers retain reserved capacity, with one model call for all eligible agents. There is no second upper network or independent ghost rollout.

Only the new endpoint evaluates the curve and updates feedback; the two accepted local poses are retained for presentation and duplicate publications. The shared bounded `ProphecyBlendClock::FKReturn` clock counts real game ticks; timestamps only identify publications. Inference eligibility and publication consume each tick once between them. In the fallback catch-up loop, returning agents commit each accepted sample before another NN step. Neither catch-up steps nor repeated publications advance the FK timer again. The clock stops at its deadline and the curve retires once both endpoints are NN-owned.

Existing Unreal presentation interpolates the two accepted policy endpoints between updates. This is an approximation of continuously evaluating the analytic lab curve between samples. The visual interpolation and lower-body timing were not replaced. Fixed-hand publication projection is bypassed while returning so it cannot overwrite the lab's parent-local offset path.
