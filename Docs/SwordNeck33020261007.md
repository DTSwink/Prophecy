## Causal controls

- Repeated baseline (`settings.json`) reproduces the crossing and gaps to submillimetre precision.
- Disabling only sword external collision after329 (`contact_off.json`) matches the approach, but trajectories diverge at332. With collision on, victim head differs by1.71cm at333 and14.62cm at340. The original collision prevention/response is therefore active; this is not simply an entirely unregistered blade collision. The existing hit audit excludes non-agent other actors, so absence of sword entries in that audit is not proof of no contacts.
- Disabling only the player's right arm magnetisation below upperarm_r after332 (`drive_off.json`) leaves the same approach and first prevention response, but reduces neck overlap at333 from3.69 to1.15cm. Some penetration remains, so this does not establish magnetisation as the sole cause or provide a complete fix. Original hand/lowerarm/upperarm linear and angular scales were1. The original sword rotates59.59degrees between334–335; with this diagnostic control it rotates8.52degrees. This is evidence that continued arm tracking contributes to forcing the blade onward after the first response.
- Bypassing the entry-gap gate at300 (`gap_bypass.json`) changes earlier wind-up interactions and victim pose before this encounter. It is confounded and cannot prove that the gate caused the neck penetration.

## Interpretation and limits

The supported finding is penetration despite an active collision response, with continued arm magnetisation contributing. Thin-blade tunnelling alone is not established. The velocity servo renews motion toward the animation each physics step. The custom PHAT sweep applies a preventive impulse, rather than imposing a hard positional barrier; subsequent contact/joint solving can still allow penetration. Already-overlapping pairs are delegated to the ordinary solver. These mechanisms explain why a detected encounter need not stop the blade completely, but the tests do not isolate the exact sweep/solver substep responsible for the remaining overlap.

No collider thickening or permanent drive changes were made. A thickness-only comparison could still test whether added geometric margin helps, but it must not be described as a proven underlying fix from this evidence.
