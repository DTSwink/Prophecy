# Temporary NN arm repellant cone and wrist twist recoil

Both NN shoulders get a mirrored cone aimed horizontally toward the opposite NN shoulder. The correction runs at final NN pose publication, after decoding, neutral-return and upper-inertia modifiers. It rotates the upper arm/elbow/hand chain together and encodes the corrected pose into the published and current upper NN state, rebasing recurrent state to the current mover frame. The kinematic NN skeleton and ordinary physical targets therefore share the correction, and the next checkpoint input sees the corrected history.

There is no physics-only target edit, torque, physical-body read, or special Jolt path. The same behavior works in kinematic and simulated modes. Cone geometry and debug drawing use the NN shoulders and NN arm directions.

## Blueprint nodes

- **Set Arm Repellant Cone**: Enabled (initially false), Cone Radius Degrees (half-angle, 0 to less than 90; default 45), Recoil Strength (default 100), Damping (default 20), Hold Out Time (default 0.3), Blend Time (default 0.5). Optional **Enable Wrist Twist Recoil** (default false), **Twist Limit Degrees** (default90, symmetric +/- allowance, valid0 to less than180), **Twist Recoil Strength** (default100), **Twist Damping** (default20).

- **Set Attack Arm Repellant Cone Enabled**: the usual 16 attack checkboxes, initially all false. Each selected attack enables recovery for both arms. Requires the master settings above.

- **Visualize Arm Repellant Cone**: on-demand drawing, with Draw Length Cm and Duration. Call on Tick for a moving view. Gray means inactive, green active/clear, red active/inside. The thick line is the presented NN upper arm direction. Drawing length has no physics effect.

Configure before attacking or in **Upper Special Ended**. The upper release starts the full-strength hold, then a smooth fade to zero. Full-to-half lower release does not start it. Pure half completion does. A replacement special, reset, master disable, zero total duration, or removal of the current attack selection cancels it. Zero cone radius/strength bypasses the cone but permits wrist-only recoil. Parry and dodge do not start it. Existing reset snapshots include configuration and selections.
