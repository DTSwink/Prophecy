# Attack forearm stretch return

`Set Attack Forearm Stretch Return(Agent, Enabled, Return Time)` is opt-in per agent. The wired PoseAgent node enables it with **0.3 authored seconds (18 game ticks)**. Both sides share the duration; each side captures its own signed length difference.

- Full and half attack entry bypass the added fixed wrist attachment. The checkpoint's native **±5 cm** hand-distance band remains. Hand-entry inertia uses the incoming attack's forearm length instead of freezing its entry length. Angular constraints, FK rotations and lower-body controls are unchanged.
- Full→half does not start a forearm return. Upper attack completion captures the presented NN forearm lengths, then linearly brings each signed difference back to its skeletal reference length. The final hand position is constrained after FK return and after presentation interpolation. The accepted upper pose is also the next NN prior.
- Physical wrists allow ±5 cm along their forearm axis during attacks. At upper release they capture their **own physical lengths**, independently of the NN, and move their attachment back to normal over the same duration. Jolt uses an extra translation-only joint while retaining the original angular joint and its frames. Chaos uses an analogous temporary constraint. No lateral or angular freedom is added by this control.
- A replacement attack cancels the old return. Reset restores the captured configuration, disabling cancels it, and mode/rig entry reapplies active settings. Only returning agents receive a bounded tick callback. A zero-length rest guard can remain until an overlapping FK return finishes, without further timer work.
- Manual `Set NN Wrist Freedom` settings remain independent. The existing always-free position pin in PoseAgent is now false, so this new node owns the attack/return window and ordinary locomotion restores its fixed attachment. Free Rotation is unchanged.

`codex GT slash` now accepts Sim and Half Sim. In these modes its preparation only resolves the original GT target in the current mover frame; it does not reseed either pose, velocity or NN history. Kinematic keeps the existing neutral-idle initialization. The two caller-side forced-Kinematic nodes are bypassed; the normal mode selector controls simulation.

Implementation and verification receipts are under `Saved/Diagnostics/AttackForearmStretch20261003/`. Live and disk Blueprint backups were captured before the normal editor build. See the receipts for actual test outcomes; physical constraints still have ordinary solver error, rather than exact positional teleportation.

Validation: normal Development Editor build succeeded and the saved Blueprint compiled with no missing native properties/pin types. Six focused tests passed (return clock/geometry/reset, signed Jolt joint, existing hand-entry reference/lifecycle and wrist math/modes). Five owned 380-tick replays covered physical, Kinematic, full→half, 36-tick and immediate return. All measured NN return curves, including their completed tails, differ from the requested linear lengths by at most 3e-7 cm. Sim GT preparation preserves the sampled pose exactly; Kinematic still seeds idle. Physical full-attack return has ordinary solver lag: about 1.15 cm on the right at the 18-tick target deadline, below 0.025 cm before the next attack. No solver iterations/gains were changed. Chaos support is implemented but these gameplay replays used Jolt or Kinematic.

The initial joint fixture incorrectly expected instantaneous tracking of a moving hard limit with two position iterations; it measured approximately 0.5 cm lag. The retained corrected test separately asserts exact signed limits and converged position without relaxing its positional tolerance. An initial Kinematic diagnostic failed on an instance-uneditable Blueprint flag and was discarded; the accepted replay switches mode after setup and verifies that it remains Kinematic. All owned Play sessions ended; TestNN remains open.
