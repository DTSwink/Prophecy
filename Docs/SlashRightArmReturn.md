All16 Boolean inputs default false. Each call replaces the entire selection; tick only the attacks that should return both arms. Unselected attacks retain their original behavior. Kicks/headbutt have no default arm return, but checking them explicitly opts both arms into the same controller.

`Set Both Arms Return To Neutral Enabled` is the per-agent master switch for this extension, initially off. Turning it off preserves the per-attack choices and cancels only the additional arm on attacks that already had an original return; for explicitly selected kicks/headbutt it cancels both, restoring their original no-return behavior. The original `Set Attack Arm Return To Neutral` remains the settings/enable node for the overall controller. Disabling that original node, setting both arms' total durations to zero, or setting both alphas to zero cancels both arms.

Configure before an attack or in Special Ended. Enabling midway through locomotion does not attach a new return to an already-running recovery. Disabling either the selected attack or the extension's master removes the additional arm immediately. Reset restores captured choices/master along with the original settings and cancels all active motion.

Both arms consume the 60 Hz clock once per pose update, with separate hold/blend durations and alphas. Each independently captures its initial hand-to-own-idle distance and keeps its own route/rotation state. The neutral chain is mounted on its own clavicle with its own authored hinge axes; both use the same anatomical torso frame. Empty left hands use shortest quaternion rotation. Actual held sword geometry and directed winding belong only to the right hand, including when it is the additional arm after a left punch. No additional model evaluation; idle decoding is shared and no second-arm pose processing occurs while unselected, disabled or finished.

## Pose contract

The destination is the authored neutral idle seed already used at initialization. The neutral orientation follows the current clavicle by default, or the current root rotation with the per-attack pelvis-position reference node. In both modes, the authored neutral chain is translated onto the actual shoulder, preserving its lengths and elbow bend. The route is measured in an anatomical frame derived from the current pelvis, neck and shoulders, so it follows the torso instead of a world-space waypoint. Selecting the left arm preserves the same right-minus-left torso frame and uses the left arm's hinge axes, lengths and neutral wrist. Held-sword geometry is used only for the right arm; left-hand routing cannot accidentally inherit the right-hand grip.

The initial distance is the full3D straight distance between the outgoing wrist
and the neutral wrist attached to the **outgoing shoulder in the selected orientation**, before the first
recovery prediction moves the torso. It is sampled once on return initialization,
stored in the return's copied speed setting, and discarded at completion or
cancellation. Saved settings/reset baselines retain the unscaled reference speed.
This is not continuous distance-based slowing or an additional arrival ease.
The existing route/turn speed bounds and ownership blend still apply.

Wrist translation now uses a straight segment when it clears the actual torso, with a smooth transition into the existing front wrap near the body. Rounded clearance caps avoid an abrupt route switch at torso height boundaries. The selected reference still carries the motion; sword and elbow guards use the actual torso. A neutral-bend-derived reach reserve prevents the active controller from locking a temporarily unreachable arm straight, fades with ownership, and leaves an already neutral pose unchanged. See [the target and routing correction](ArmReturnReachAndDirectPath.md) and [the reference node](ArmReturnReference.md).

Hand rotation is calibrated from the held sword's mesh bounds and actual grip transform: its long blade axis returns to anatomical forward. Yaw is explicitly unwrapped, rather than shortest-arc quaternion slerped. Both rotation windings are evaluated against the blade's torso clearance along the return; this permits the longer outward turn in the user's sketch without forcing a needless revolution when the blade already points forward. Rotation shares the wrist's route progress. A padded segment guard includes grip offset, blade length and cross-section, moving an unsafe wrist target outward on its existing side. These are recovery pose checks, not changes to sword collisions or physical constraints.

A connected two-bone solve transports both source hinges to the same final wrist before blending their bend directions. It gradually restores coherent idle/NN guidance; wrist roll does not independently orbit the elbow. Nearly straight or ambiguous guidance retains the previous bend rather than amplifying numerical noise. A torso-envelope guard checks both shoulder–elbow and elbow–wrist segments and rotates the elbow on its exact IK solution circle toward the nearest clear solution. It preserves both lengths and the wrist target. Boundary refinement avoids discrete pole snapping; its turn rate is bounded, permitting gradual escape from an already-penetrating attack pose. Wrist-derived forearm roll retains the shared locomotion/specials convention. See [the elbow correction and validation](ElbowRecoveryBend.md).

The result is stored in the accepted upper-body state, feeding subsequent NN inputs and publication/physical targets. It runs after existing hand recovery, tempering and inertia: the return controller owns the selected arm(s) during its hold, then yields to those ordinary controls. With the extension off the other arm is untouched. FK core, legs, root and special poses are not directly modified; changed accepted hand inputs may influence later NN outputs. Existing physical constraints and authored clamp settings remain in force.

This uses an anatomical torso envelope and the held blade geometry, not an environment collision planner or a guarantee against every physical self-contact. It cannot repair arbitrary pre-existing body penetration or make an unreachable wrist target reachable. Existing target clamps may further constrain the decoded wrist. At the end, ordinary NN/tempering controls resume exactly.
