The ordinary **Add Static Mesh Component** node creates a stock Unreal component. Its initial **Set Simulate Physics**, mass and velocity nodes configure Chaos. Chaos bodies and Jolt bodies do not exchange simulation contacts.

For the existing `launch ball debug` graph, keep its setup and add **Enable Jolt Static Mesh Physics** after **Set Use CCD**, passing the same Add Static Mesh Component return value. The adapter imports the configured shape/scale, pose, mass/inertia, velocity, gravity, damping, material, collision channels and CCD at admission. CCD uses Jolt LinearCast. Rendering, component reference, materials, ownership and Unreal trace receiver are retained. Jolt takes exclusive simulation ownership; the Chaos body becomes a query proxy. Multiple independent components can belong to one pawn; its root/capsule is not replaced or moved by publishing those components.

When called during actor Tick, admission may wait for the next safe world boundary. This node captures/prepares the launch immediately and freezes the Chaos proxy while queued, then creates the Jolt body from that exact snapshot. It cannot travel an uncollided Chaos frame before Jolt receives it. Pending launch storage is event-only and removed on admission/cancellation; ordinary existing body-adapter handoffs retain their previous behavior.

**Is Jolt Static Mesh Physics Enabled** reports actual native ownership. **Disable Jolt Static Mesh Physics** retires an adapter created by the enable node and leaves simulation off; it does not automatically restart Chaos. Ordinary **Destroy Component** also retires the library-owned adapter/body. Event-only tracking is active only while these adapters exist; no world scan or additional component Tick is introduced.

This is an explicit handoff node, not a replacement of Unreal's global physics backend. Stock StaticMeshComponent force/velocity functions remain Chaos methods after admission. For subsequent standard Add Force / Add Impulse / Set Physics Velocity calls, use the existing **Prophecy Physics Static Mesh Component** class (Add Component by Class), then the same enable node after initial setup.
